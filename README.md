# 🎬 Movie Logbook

A private, high-performance shared movie tracking dashboard designed exclusively for a close-knit group of friends. 

## ✨ Features
- **No-Auth Entry:** Frictionless identity selection without traditional passwords.
- **Shared Library:** Real-time synchronized movie database.
- **Independent Watch Status:** Track whether each individual member has watched a specific movie.
- **Smart Search:** Instant client-side filtering by movie name and genre.
- **Analytics & Leaderboard:** Dynamic watch history, progress tracking, and competitive ranking.
- **Personal Wishlist:** Individualized lists for future movie planning.

## 🛠️ Tech Stack
- **Frontend:** React, Vite, Tailwind CSS
- **Backend/Database:** Supabase (PostgreSQL)
- **Design System:** Minimalist dark cinematic UI with Glassmorphism elements
